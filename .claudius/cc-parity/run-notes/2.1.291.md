# Claude Code parity 2.1.289 → 2.1.291

## Summary

Claude Code 2.1.290 is a very large release, and 2.1.291 is two regression fixes. Almost all of it is engine behaviour that ships inside the bundled CLI binary and reaches Claudius through the SDK updater. The rest is terminal-only (`claude agents` / agent view, `claude attach|logs|respawn|daemon`, TUI pointers and key chords), VS Code, Slack (Claude Tag), cloud-session, gateway, or plugin-mod (`turn.step`, `tool.check`) work that has no Claudius counterpart. The paired SDK update (0.3.290 → 0.3.291) was a parity-only bump, and its notes record no type-surface change. No bucket-B items apply this release, so Claudius gets no new UI. The headline risk is a false negative in classification: the 2.1.290 entry list is long and mostly thin, so a reviewer should skim the bucket assignments below.
