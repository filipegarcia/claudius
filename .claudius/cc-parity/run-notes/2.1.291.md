# Claude Code parity 2.1.289 → 2.1.291

## Summary

Claude Code 2.1.290 is a very large release, and 2.1.291 is two regression fixes. Most of it is engine behaviour that ships inside the bundled CLI binary and reaches Claudius through the SDK updater, or terminal/VS Code/Slack/cloud/gateway/plugin-mod work with no Claudius counterpart.

The first automated pass shipped no bucket-B items. A manual re-audit against the code found six entries that touch surfaces Claudius owns, and all six now ship: deeply nested markdown no longer crashes the chat, the Skills page lists non-English skill folders and shows the SKILL.md name, the doctor flags a project-scope `CLAUDE_CODE_DISABLE_ATTACHMENTS`, message timestamps show by default (`showMessageTimestamps`), the `/` and `@` pickers mark the selected row with `❯`, and a mid-turn send announces "Message queued." to screen readers. The headline risk is the timestamps default: every user now sees times on every bubble unless they turn it off.

## Implemented (bucket B)

- `[2.1.290] Deeply nested markdown` — new `lib/shared/markdown-nesting.ts`: a linear, fence-aware pre-scan of blockquote and list nesting, with the cap at 64 levels (a 64-level list renders in ~15ms; 200 levels take ~250ms). `components/chat/Markdown.tsx` memoizes the scan per text and renders plain text plus a one-line note past the cap, and wraps react-markdown in an error boundary that falls back to plain text for any other render throw and resets when the text changes. Every bubble (assistant, user, task, plan, transcript viewer) goes through this component. Rejected alternative: a remark plugin that flattens deep nodes — it would still let the parser run on the pathological input, and the pre-scan avoids that whichever stage overflows.
- `[2.1.290] Skills listing` — `lib/server/skills.ts` uses one Unicode-aware folder-name rule (letters, marks and digits in any script, plus `_ . -`, no leading dot) for listing, read/write and delete; `deleteSkill` now also goes through `assertWithin` and refuses to resolve to the skills directory itself. `app/[workspaceId]/skills/page.tsx` shows "folder · SKILL.md name" in the list and the editor header when the two differ (NFC-compared, via the new `lib/shared/skill-names.ts`), and search matches either. Creating a skill keeps the ASCII rule. Rejected alternative: showing the SKILL.md name as the primary label — the folder is the identity the page edits and deletes by.
- `[2.1.290] Attachments env doctor check` — `app/api/doctor/route.ts`'s ignored-env scan (formerly the telemetry-only check) reads each workspace's project/local env once and adds an "Ignored attachments env" warning, via `ignoredAttachmentsEnvKeys` in `lib/shared/telemetry-env.ts`. The telemetry check's id, label and wording are unchanged. Claudius passes only its own process env to the CLI (`buildQueryEnv`), so a project-scope value reaches the engine solely through settings.json, where it is now ignored. Rejected alternative: an inline warning in the env editor — the doctor already owns this class of warning.
- `[2.1.290] Message timestamps by default` — bubbles always show their time unless the user-scope `showMessageTimestamps` (the SDK's own key) is false, which restores hover-only. Read once by `lib/client/useShowMessageTimestamps.ts` in `components/chat/ChatSurface.tsx` and shared through `lib/client/message-timestamps-context.ts`; `UserMessage.tsx` and `AssistantMessage.tsx` apply it, and ultra-verbose still adds seconds. Settings → Chat gets a toggle (`app/settings/page.tsx`, typed in `lib/server/settings.ts`). Rejected alternative: keep hover-only and add an opt-in — upstream changed the default, and Claudius's chat is the closest analogue to the VS Code panel.
- `[2.1.290] ❯ pointer` — `components/chat/SlashCommandPicker.tsx` and `components/chat/AtMentionPicker.tsx` render an aria-hidden ❯ column on the selected row and an empty fixed-width cell elsewhere, so nothing shifts. Rejected alternative: a CSS `::before` glyph — a real aria-hidden span is just as invisible to assistive tech and easier to test.
- `[2.1.290] "Message queued." announcement` — `components/chat/ChatSurface.tsx` adds a polite live region; `handleSend` announces when a plain message is sent while a turn runs. Keyed off the send rather than the queue length, because `queueDispatchMode: "asap"` sends skip Claudius's queue. Rejected alternative: announcing from `QueueIndicator` — it unmounts when the queue is empty and never sees asap sends.
