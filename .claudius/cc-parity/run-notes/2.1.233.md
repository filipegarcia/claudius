## Summary

Between 2.1.228 and 2.1.233 upstream shipped a large batch of work, but the
overwhelming majority is engine/CLI/enterprise-gateway internals that either
land automatically via the SDK updater or have no analog in a browser app
(Remote Control, self-hosted runners, VSCode-extension fixes, terminal
rendering/screen-reader tweaks, `claude agents`/`--worktree` CLI flags). A
sizeable chunk of what looked like real bucket-B candidates at first glance
— the `/config` rows for `dialogExpiry`/cross-session-inbound, the
`additionalMarketplaces`/`allowedMarketplaces` settings aliases, and the
Fable 5 advisor re-offer, all from 2.1.232 — turned out to already be
shipped on `main` from an earlier consolidated parity pass (commit
`33ccb05`, PR #202, "Claude Code 2.1.221–233 feature parity"); this run
confirmed their presence rather than re-doing them (see Risks — that PR's
existence also means an even earlier classification of `dialogExpiry`/
crossSessionInbound as pure bucket A, recorded in `run-notes/2.1.227.md`,
is now stale). Similarly, "Updated agent panel: completed subagents hide
immediately" (2.1.232) turned out to already be true of Claudius's own
`BackgroundTasksPanel` (its "Tasks" section already filters to
running/pending only) — no gap, no code change. The one genuine, previously
un-shipped bucket-B item this release: upstream removed its CLI startup tip
suggesting the user create custom subagents (2.1.232); Claudius's own
spinner-tip catalog (`lib/shared/tips.ts`) had a direct 1:1 mirror of that
exact tip, so it's retired here to match. Headline risk to flag for review:
the stale 2.1.227-era classification noted above, and the general pattern
of gateway/enterprise items (`forward_user_identity`, managed-policy
validation, etc.) being folded into bucket A as "invisible to Claudius"
rather than bucket C — see Risks for why.
