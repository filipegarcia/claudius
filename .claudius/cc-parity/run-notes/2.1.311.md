# Claude Code parity 2.1.310 → 2.1.311

## Summary

(Draft — finalized after implementation.) Claude Code 2.1.311 is mostly engine, CLI, cloud and VS Code work. Six fixes land on surfaces Claudius reimplements and are mirrored here: the `ultrathink` keyword detector now ignores quoted words and file paths; voice dictation stops when a message is sent; a lone backslash in `"\"` / `(\)` / `[\]` no longer disappears from rendered replies; a session whose SDK process died between turns is restarted on the next message instead of silently dropping it; a refused pasted sign-in code gets Claude Code's new wording; and the Restore-files confirmation no longer suggests that saved manual/Bash edits are safe.

## Changelog classification

Context: the CLI binary bundled with SDK 0.3.311 (`node_modules/@anthropic-ai/claude-agent-sdk-darwin-arm64/claude`, read with `strings`), the public `sdk.d.ts`, and a grep of each matching Claudius code path. The SDK migration on this branch (`3c14f408`, `40466e39`, `62fafb73`) bumped the dependency and made `ModelUsage`'s new 5m/1h cache-creation split accumulate across resumes. No CC changelog entry overlaps that change, so no line below needs the "already shipped via SDK migration" tag.

## Risks / follow-ups

(Draft — expanded after implementation.)

- `ultrathink` xhigh boost deferred. The SDK has no turn-scoped effort, and a session-scoped `applyFlagSettings` override plus a restore could leave a session stuck at xhigh after a crash, a reap or a mid-turn `/effort`.
- `DISABLE_COMPACT` is not reflected in Claudius's Compact buttons and `/compact` entry. This gap predates the release; it is not the CC bug.
- Pro/Max "contact your administrator" credits CTA (`lib/client/rate-limit-cta.ts:27-28`). Similar flavour to the CC fix, but a different trigger, and not shown to be reachable.
- `!`-mode timeout result doesn't say the command timed out.
- Task list after resume for teammate/subagent task calls.
- MCP SDK-only rows mislabelled "Local (.claude/settings.local.json)"; deleting them silently does nothing.
