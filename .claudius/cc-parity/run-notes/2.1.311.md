# Claude Code parity 2.1.310 → 2.1.311

## Summary

Claude Code 2.1.311 is mostly engine, CLI, cloud and VS Code work, and most of it reaches Claudius through the SDK 0.3.311 bump already on this branch. Six entries land on surfaces Claudius reimplements and are mirrored, each by extending an existing screen:

1. The `ultrathink` keyword detector ignores quoted words and file paths.
2. Sending a message stops voice dictation.
3. A lone backslash in `"\"` / `(\)` / `[\]` stays visible in rendered replies.
4. A session whose SDK process died between turns is restarted on the next send, queue send or tab reconnect, instead of silently dropping input, and the error banner says how to resume.
5. A refused pasted sign-in code gets Claude Code's new "sign in again" wording, and the form starts over.
6. The Restore-files confirmation no longer suggests that saved manual/Bash edits are safe.

An adversarial review pass found real bugs in four of the six, and all were fixed before the gates:

- **Ultrathink:** a server-wide hang from a non-string `inlinePastes` entry, plus quadratic scans.
- **Backslash:** code in blockquotes and lists, and URLs, now showed a doubled backslash.
- **Dead session:** the queue and loop-cancel routes still dropped input, and polling could use up the restart budget.
- **Dictation:** a failed send's restored text could be overwritten.

Headline review risk: the dead-session restart, which touches the session lifecycle and has already caused one CI regression (fixed in `7e183a25`). The upstream case of an *unattended* session with a scheduled loop is not covered (see Risks).

## Risks / follow-ups

**Design calls on the shipped bucket-B items** (each has its rejected alternative under Implemented):

- **Dead-session restart scope (conservative vs maximal).**
  - Shipped (conservative): restart on demand, when the user sends, a queue item is sent, or a tab connects.
  - Maximal: restart as soon as the process dies, and restart unattended sessions that had a scheduled loop or wake-up armed, which is the upstream case.
  - Not done because Claudius's session crons and wake-ups live inside the SDK process. A resumed process doesn't re-arm them, and the replayed transcript only rebuilds Claudius's *display* of the loops. A real fix needs Claudius to re-arm loops after a restart, a new mechanism.
  - Today a dead session with armed loops is no longer pinned forever. Once no tab is attached, the reaper releases it.
  - Loop cancel on a dead session answers 410.
- **Dead-session edge cases left as-is.**
  - The restarting tab keeps the old red "process exited" error and hint until the next send, the same lifetime as any other session error. Clearing on `ready` would also clear them when the tab binds to a still-dead instance.
  - A process that ends cleanly without the iterator throwing is `isDead()` but gets no banner. Its next send still restarts it.
  - If a deliberate `remove()` (for example a workspace move) lands *during* a failed rebuild, the failed-rebuild path re-registers the dead instance.
  - `persistSession: false` sessions have no transcript to resume, so "the conversation so far is kept" isn't true for them.
- **Dictation drops the end of what you said.** Sending stops the mic and discards the not-yet-final transcript, so trailing words spoken after the last interim are lost. The alternative is to flush the audio and wait briefly for the final transcript, then send. That's more faithful to "stops dictation first" if CC waits, but it adds a send delay. Reviewer call.
- **Lone backslash is narrow by design.**
  - Skipped: blockquote lines, indented (4+) lines, URLs, link syntax and HTML attributes, which keep the old CommonMark rendering, and text inside `$…$` math.
  - Known misfire: `"\"hello\""` renders as `"\"hello""` (the first `\"` is treated as lone).
  - Still lost, as before: `"C:\temp\"` and `(C:\)`.
- **Ultrathink follows the engine exactly**, including where that differs from the old Claudius regex:
  - curly quotes don't count as quotes;
  - a trailing `?` suppresses the keyword (`should I ultrathink?`);
  - a prompt starting with `/` never matches.
- **OAuth refused code.** A non-`invalid_grant` failure also resets the form to "Sign in", because the flow is spent on any attempt. The `/welcome` variant isn't screenshotted (server-side redirect); it shares the server message and the same reset.
- **Restore copy.** "Removing any it created since" relies on the SDK's `rewindFiles` doc ("restored or deleted"); not verified against a live rewind.

**Skipped or deferred entries:**

- **`ultrathink` xhigh boost (deferred).**
  - In the bundled CLI it is gated on the terminal composer.
  - The SDK has no turn-scoped effort.
  - A session-scoped `applyFlagSettings` override plus a restore could leave a session stuck at xhigh after a crash, a reap or a mid-turn `/effort`.
  - Maximal shape: wrap the turn in an effort override with a guaranteed restore, once the SDK exposes per-turn effort.
- **Explanatory output style tip (not built).**
  - Conservative shape, shipped: no tip.
  - Maximal shape: a new tip trigger in `lib/shared/tips.ts` that matches the outgoing prompt ("explain…", "why does…") and suggests the Explanatory style.
  - Not built because Claudius tips are random-only, and a prompt-content trigger is a new mechanism. A plain random tip wouldn't match the CC behaviour.
- **Agent teams task list after resume.** Plausible for teammate/subagent task calls, which aren't on the main transcript chain, but not reproduced.
