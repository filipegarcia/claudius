- `[C — CLI/terminal only] Improved the /diff panel (no more "0 files changed" flash, centered empty state)` — this is a fix for the CLI's Ink-rendered terminal panel, which progressively repaints as data streams in. - `[A — already via SDK updater] Improved the Bash tool's description guidance` — this is system-prompt/tool-schema wording baked into the agent SDK's built-in Bash tool; it ships automatically when the SDK updater bumps `@anthropic-ai/claude-agent-sdk`.

- `[A — already via SDK updater] Improved --resume first-render time for sessions with many Bash tool calls` — session-resume performance is engine-internal (transcript replay), inherited via the SDK's `query()` resume path that Claudius already uses.
- `[C — CLI/terminal only] Improved prompt input responsiveness (keystrokes no longer wait behind spinner/streaming repaints)` — this is specifically about the CLI's Ink terminal input loop contending with terminal repaints; Claudius's prompt input is a React DOM `<textarea>` with its own independent render path, not subject to the same contention.
- `[A — already via SDK updater] Improved prompt-cache stability for subagents/sessions started with --system-prompt or --append-system-prompt` — prompt-cache/system-prompt recording is engine-internal state managed by the SDK.
