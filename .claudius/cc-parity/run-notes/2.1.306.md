## Summary

Claude Code 2.1.306 ships two bug fixes and no new features. The first stops `claude -p` from reporting "Not logged in" inside cloud sessions, which is cloud and CLI only. The second stops an API error from being replaced by "prompt is too long" (and an unneeded compaction from running) in sessions with many MCP tools, which is engine-side. Neither bug has a copy in Claudius's own code. The engine fix already reaches Claudius through the `@anthropic-ai/claude-agent-sdk` 0.3.306 bump on this branch, which is the SDK's "parity with Claude Code v2.1.306" build. So there are no bucket-B items, no new UI and no product code changes this release. The main thing to review is the classification: confirm that Claudius has no own error-rewriting or auto-compaction path. The files checked are listed per entry below.

## Changelog classification

- `[C — CLI/terminal only] Fixed \`claude -p\` inside cloud sessions reporting "Not logged in" when started without the session's environment variables` — This is cloud-session CLI behaviour. Claudius never spawns `claude -p`. The only `-p` spawn in the tree is `next dev -p <port>` in `lib/server/preview-server.ts:454`. Claudius authenticates through the SDK and its own accounts UI. `lib/server/auth-failed-detector.ts` only matches 401 / "failed to authenticate" text and the `authentication_failed` enum, never "Not logged in". There is nothing to mirror.
- `[skip — already shipped via SDK migration on this branch] Fixed an API error being replaced by "prompt is too long", and an unneeded compaction, in sessions with many MCP tools` — Bucket A. The error mapping and the auto-compaction decision both live in the engine bundled with the SDK, and the 0.3.306 bump (`449ecdf5`, "parity with Claude Code v2.1.306") already carries the fix. I grepped Claudius for an own copy of the bug and found none:
  - **No error rewriting.** No file under `lib/`, `app/` or `components/` produces or matches "prompt is too long". `lib/server/cost-aggregate.ts:135` only drops `<synthetic>` model turns from cost totals. The API-error detectors (`opus-overload-detector.ts`, `auth-failed-detector.ts`, `long-context-credits-detector.ts`, `thinking-replay-recovery.ts`) read the SDK's structured `error` enum or the "API Error" text. None of them rewrites an error into a context-overflow message or retries on one.
  - **No Claudius-triggered compaction.** The context-warning banner (`lib/client/useContextWarning.ts`, `components/chat/ContextWarningBanner.tsx`) displays the percentage the SDK reports. That number comes from `session.getContextUsage()` in `app/api/sessions/[id]/context/route.ts:17`. The banner only compacts when the user clicks it. The `idleCompaction` setting (`lib/server/settings.ts:304`) is forwarded to the engine. Claudius never counts MCP tool tokens itself and never fires `/compact` on an error.
