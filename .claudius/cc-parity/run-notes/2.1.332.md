## Summary

A catch-up across five Claude Code releases, 2.1.328 to 2.1.332: 701 changelog entries. The pipeline stopped at 2.1.327 because of #383; that fix is #384. Each release was audited bullet by bullet against the Claudius code it touches, by one triage agent per release. The 54 entries where Claudius has its own copy of the bug or gap were implemented in parallel by five agents, one per surface: composer, prompts and dialogs, config pages, session state, and diagnostics. Each change was then checked against its diff before it was integrated. 52 of the 54 are shipped. The other two (2.1.331 #85 and #90) are skipped as ambiguous, because building them would mean guessing at engine behaviour that neither the SDK typings nor the code settle.

What changed for the user:
- **Composer**
  - Typing with an input method (Japanese, Chinese, Korean) no longer answers a permission prompt, picks an @ file or closes a dialog when it commits or cancels a conversion.
  - Holding Enter after an @ or / pick no longer sends the message.
  - Menus reset their highlight as you type.
  - The @ menu waits for its search, lets Enter send an unmatched `@word`, and says when it couldn't search every file.
  - Cmd/Ctrl+Shift+↑/↓ selects text again.
  - Editing a recalled prompt keeps the unsent draft.
  - On macOS, Ctrl+F moves the caret instead of opening find.
  - An image pasted into a `!` command goes in as its path.
  - Dictation stops, and says why, when you edit the message, the microphone is lost, or the window stays hidden.
- **Prompts and dialogs**
  - The permission card fits a short window and says why a safety check asks.
  - It offers only Allow once and Deny under managed-only rules.
  - Plan approval offers "Accept & use auto mode".
  - The question modal picks the highlighted option on Enter, keeps working after Other, ignores Ctrl/Alt+digit, and lays out right-to-left text correctly.
  - Dialogs no longer close when a text selection is dragged past their edge.
  - Restore files no longer spins forever.
  - A model pick or a file restore now works after the session's process ended.
  - Notifications name the waiting session.
- **Config pages**
  - `/hooks` saves `mcp_tool` hooks in the shape the engine loads. Every one Claudius wrote before was skipped at load.
  - `/hooks` also gets `onFailure: "block"` for `mcp_tool` and the new `PreSkillShellCommand` event.
  - `/permissions` refuses rules the engine would skip.
  - `/mcp` says where non-file servers are managed and shows why a Reconnect failed.
  - Marketplace Remove asks first, and a double click no longer removes two entries.
  - `/plugins` Discover reports a failed load and an empty search.
  - Settings saves that land together no longer lose each other's changes.
  - An empty or BOM-prefixed settings.json reads as valid.
  - An unreadable `jobs.json` can no longer erase the other saved jobs.
- **Session state**
  - Loops run up to 30 days and show when they end.
  - A fork no longer runs its source's loops.
  - Usage-credit states are named correctly: out of credits, used up, and credits in use.
  - `/cost` shows credit amounts in dollars, not cents.
  - A reply that merely starts "You've hit your…" is no longer a usage-limit stop.
  - A background task that finishes while idle leaves a notice.
  - `spinnerVerbs` is honoured.
- **Diagnostics and rendering**
  - `/doctor` tests API connectivity, and `/doctor` and `/status` flag an OpenTelemetry exporter that has no endpoint.
  - `/status` names the plan-mode model for `opusplan` and `haiku`.
  - Picking Default no longer writes `"model": "default"`.
  - Long or malformed markdown renders as plain text instead of freezing the tab, and a single tilde no longer strikes text through.
  - Links to extensionless files and folders open the Files view.
  - WebFetch HTTP errors and redirects no longer show a green check.
  - "Routine" now reads "cloud scheduled task".
  - The resume-gap line no longer blames a damaged file, and an on-hold sign-in shows the on-hold notice.
  - The desktop app no longer leaks `ELECTRON_RUN_AS_NODE` into commands, hooks and MCP servers.

Headline review risks:
- the settings lock is in-process only;
- the `mcp_tool` legacy-shape badge, rather than a migration;
- the dictation hidden-window threshold, which is Claudius's choice;
- the idle task notice is proven on replay but not in a live session.

All four are covered in Risks below.

## Risks / follow-ups

- **Settings lock is in-process.** It serializes Claudius's own writers but can't stop an engine process writing `settings.json` between Claudius's read and write. The 2.1.318 MCP lock has the same stated limit. The engine uses `<file>.lock` lock files; adopting them needs the exact lock path confirmed first.
- **Legacy `mcp_tool` hooks are badged, not migrated.** Splitting `mcp__srv__tool` back into server and tool is ambiguous when either name contains `__`.
- **Dictation hidden-window stop.** It fires after 30 s hidden. The engine stops when "the panel stays hidden" but its threshold isn't published, so 30 s is Claudius's choice.
- **Idle task notice.** It is proven on replay. Whether the top-level wrapper reaches the client during a live idle session wasn't established from the SDK; live and replay share the same code path.
- **Plan "Accept & use auto mode".** It shows whenever `disableAutoMode` is off. On a model that can't run auto, the server falls back to acceptEdits, the toast says "auto mode requested", and the mode badge shows what actually happened.
- **Managed-only rules.** The flag is read once in `start()` without blocking, so a prompt raised before that read finishes may still show the Always buttons.
- **`/doctor` connectivity.** The engine's separate Sign-in probe is not ported. There is one Claudius-only skip reason: Node's `fetch` ignores `HTTPS_PROXY`.
- **On-hold sign-in.** Claudius parses the on-hold token response unconditionally; the engine does so behind a flag. A custom `CLAUDE_AI_ORIGIN` appeal link is not linked, and falls back to claude.ai/restricted.
- **Skipped as ambiguous:**
  - 2.1.331 #85 (stop the turn on a mid-turn restore) and #90 (@-mentions after `cd`); see their rows.
  - 2.1.329 #4, #5, #111, #120; 2.1.330 L3, L4, L140; 2.1.331 two rows; 2.1.332 #73, #85, #97. Each row records the alternative that was rejected.
- **Follow-ups seen during the audit, not part of these releases:**
  - The Cost page prices fast-mode turns at standard rates (`lib/server/cost-aggregate.ts`), because `litellm-prices.json` has no fast rates.
  - The permission card has no ARIA live region (2.1.329 #120).
  - Hide "Restore files" under a managed `fileCheckpointingEnabled: false`.
