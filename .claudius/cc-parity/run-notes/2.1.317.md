## Summary

_(Draft — finalized after implementation.)_ Claude Code 2.1.317 is almost entirely engine, terminal, cloud, gateway, self-hosted-runner, VSCode and Slack work. ## Implemented (bucket B)

- `[extend: session revive (no UI change)]` **(planned)** **A permission-mode change survives the idle reaper and a server/app restart.**
  - Planned shape: record `{ permissionMode, permissionModeAt }` in the session's state bag each time Claudius commits a mode. That covers `applyPermissionMode` after the engine accepts, and the plan-acceptance write in `resolvePlan`.
  - `resumePermissionMode` then compares that record with the timestamp of the transcript's last prompt, and the newer one wins. The 2.1.292 plan-only carry-over is unchanged.
  - Rejected alternative: carrying every mode across a revive. That would widen what a revived session may do, against the plan-only policy.
