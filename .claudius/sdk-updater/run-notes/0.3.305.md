## SDK changelog highlights

Changelog items:

- `get_usage` behavior windows gained `recommendations` and `fix` (0.3.305) — `recommendations` **[shipped]** (parsed in `lib/shared/usage-behaviors.ts`, rendered in the Cost overlay's "What's contributing to your limits usage?" section); `fix` **[skipped — the fix is a list of user messages (`/effort …` commands plus one composed prompt) that the host must send into the running session at priority `later`; wiring that into Claudius's composer/queue is a separate feature, and the recommendations text already tells the user what to do]**.
- `setMcpServers` servers no longer replaced by same-named user-settings server (0.3.305) — **[skipped — CLI-side behaviour fix, no API change; Claudius's `mcp-dynamic` route calls `setMcpServers` unchanged]**.

- `suspendSseStream(query)` / `resumeSseStream(query)` (browser SDK, 0.3.304) — **[skipped — browser-SDK-only export for `sse` remote queries; Claudius runs the Node SDK and streams to its own browser over its own SSE route]**.

- Fork subagents on by default in SDK sessions (0.3.302) — **[skipped — runtime behaviour in the CLI; the `Agent` tool UI renders by tool name/input and needs no change; `AgentInput.effort` doc note ("ignored for fork") is doc-only]**.
