## Summary

`0.3.252` is a pure parity bump to Claude Code v2.1.252 with no
Claudius-visible surface change. The upstream changelog is a single
"Updated to parity" line, the orchestrator's `.d.ts` diff is byte-identical
between `0.3.251` and `0.3.252` (zero new declarations), and an independent
`npm pack` diff of both tarballs confirms the only differences are: the
`manifest.json` CLI-binary checksums/sizes for each platform, the
`claudeCodeVersion` string, the `optionalDependencies` version pins, and
internal minified-bundle content in `sdk.mjs`/`bridge.mjs`/`browser-sdk.js`
with unchanged occurrence-counts for every model-identity, pricing, and
capability keyword we checked (`fable`, `modelPicker`, `modelPricing`,
`promptCacheTtl`, `managedSourcesBehavior`, `default_to_no`, `1m`/`[1m]`).
We made no code changes — the only non-notes diff against `origin/main` is
the version bump (`package.json`, `bun.lock`) that the orchestrator already
applied. Headline risk: a future release with an actual `.d.ts` diff should
not be assumed to be this quiet just because this one was — this audit's
"no code changes" conclusion is specific to `0.3.252` and must be
re-verified from scratch next time.
