## Summary

This PR is a rolling continuation of #261 (already open for 0.3.274 →
0.3.275) picked up further by this run to 0.3.276. The 0.3.274 → 0.3.275
half shipped `Options.projectConfigRoot` — wired in `lib/server/trusted-cwd.ts`
+ `lib/server/session.ts` so a session opened directly inside a git worktree
loads project settings/hooks/`.mcp.json` from the trusted root instead of the
worktree's own checked-out branch — plus five transparent upstream bug fixes
Claudius gets for free, and a batch of `artifact`-tool (claude.ai web
publishing) input/output fields that remain unreachable because Claudius's
coding-agent SDK usage never issues or renders that tool. The 0.3.275 →
0.3.276 half itself is a bare "parity with Claude Code v2.1.276" line with
**zero** new public declarations — the type-surface diff for this window is
byte-identical to 0.3.275's (same `sdk.d.ts`/`sdk-tools.d.ts` additions,
re-audited fresh below, same conclusions). So this run's own marginal work is
the version bump (`eff6a93`) plus these notes; no new Claudius code was
required on top of what #261 already shipped. Headline risk to flag: PR #261's
title still reads "...0.3.275... 2.1.274 → 2.1.275" and needs updating to
reflect the final 0.3.276/2.1.275 range before merge (see Risks/follow-ups).
