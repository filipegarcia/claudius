# SDK update 0.3.325 → 0.3.326

## Summary

0.3.326 is mostly a hardening/parity release (Claude Code v2.1.326): a new `mcpServersDelivery` option (deprecating argv delivery of `mcpServers`), `getSessionInfo()` on `/core`, MCP reconnect fixes, and a sandbox-aware `rewindFiles()` that skips more files. Claudius only passes an in-process SDK MCP server (`claudius_goal`) via `Options.mcpServers`, which the delivery option explicitly does not affect, so no migration was needed there. The one user-visible consequence is that `rewindFiles()` now reports sandbox-related skips through the existing `skippedLinks` count, so the rewind "Files restored" warning copy was widened to name that cause. Headline risk: low; the change is copy-only.
