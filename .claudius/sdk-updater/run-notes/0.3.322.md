# SDK update 0.3.317 → 0.3.322

## Summary

The 0.3.317 → 0.3.322 window (five point releases, four of them bare "parity with Claude Code v2.1.318–322") adds a few optional public fields plus a lot of CLI-internal hook/permission/session robustness fixes. By the time this run started, `origin/main` already carried every Claudius-facing adaptation for the 0.3.317–0.3.321 part of the window (PR #350/#352 and the cc-parity 2.1.319/2.1.321 work: `endedLoopWakeup`, `credential_expires_at`, `config_file_invalid`, `denyInsteadOfPrompting`, `disableReplyCheck`, `disableWindowsBashCommandSplit`). This branch adds the `^0.3.322` dependency and mirrors the doc-only `Settings` JSDoc changes from the window into the Settings catalog copy (`fastMode` Vertex note, `cleanupPeriodDays` local-only note, `attributionProject` `chan_` ids). Headline risk: none; the code diff is three description strings.
