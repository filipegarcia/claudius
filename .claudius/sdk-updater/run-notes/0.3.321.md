# SDK update 0.3.317 → 0.3.321

## Summary

The 0.3.317 → 0.3.321 window (four point releases, three of them "parity with Claude Code v2.1.318–321") adds a handful of optional types and a lot of CLI-internal hook/permission/session robustness fixes. By the time this run started, `origin/main` already carried the `^0.3.321` dependency and every Claudius-facing adaptation from this window: PR #350 (the 0.3.319 → 0.3.321 SDK update: `CronDeleteOutput.endedLoopWakeup` wiring and the `forceLoginMethod` wording), the 0.3.319 SDK-update notes (`config_file_invalid` label, `disableReplyCheck` / `disableWindowsBashCommandSplit` settings rows), and the cc-parity work (`credential_expires_at` sign-in banner, `denyInsteadOfPrompting`). This re-run therefore re-audited the full 0.3.317 → 0.3.321 type surface against the code on main, found no remaining gap, and produces no product-code diff: the only commit-level change is the notes file, plus reverting the orchestrator's bump commit's accidental version regression in `package.json` (0.3.322 on main → 0.3.321 on the branch). Headline risk: none new; every item below is either already shipped on main (with the file named) or a deliberate skip.
