# SDK update 0.3.306 → 0.3.311

## Summary

0.3.306 → 0.3.311 is a small window: the only host-visible addition is `ModelUsage.cacheCreationEphemeral5mInputTokens` / `cacheCreationEphemeral1hInputTokens` (split of `cacheCreationInputTokens` by cache lifetime). Claudius accumulates per-model usage across SDK processes via an additive-field allowlist in `lib/server/session.ts`; the two new counters would otherwise have been last-write-wins on resumed sessions, so they were added there with a vitest. Everything else is CLI parity, managed-settings fixes, bridge/browser-SDK surface, or SDK-internal tooling that Claudius doesn't call. Headline risk: low; the new counters are persisted only inside the `modelUsage` JSON blob and not yet shown in the UI.
